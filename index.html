THE SMART

An Arabic-first exam-prep platform for the Algerian baccalauréat. Students practise on real past papers, take a daily quiz, follow chapter-ordered lessons and ask an AI tutor that answers the way an exam paper is written.

  • Four AI features: tutor, mistake explainer, flashcard generator and exam solver

Odoo 19 platform for a university group

I’m currently on a 3-month internship in a three-developer team building the group’s ERP on Odoo 19 Community — custom modules on the official Docker image, no fork. Together, the platform replaced a GoHighLevel CRM and an Excel admissions workbook. My part so far:

RFID meal credits

The card holds only an ID; credits live on the server. One meal = one credit, an append-only ledger, row locks so two tills can’t spend the last credit, and a Postgres CHECK that makes a negative balance impossible. 43 tests, proven on real RFID hardware.

University maintenance

Requests, inspections, findings and a dashboard — with a reporter role, a submit workflow, multi-photo reports and a “My Work” day view for technicians.

Campus+ teacher recruitment

Web form → scoring engine → per-campaign ranking → an 8-step hiring sequence enforced in Python, so no script can skip a step.

POS identity & procurement

The HIS visual identity across three touch-friendly tills, and the procurement-needs (besoin d’achat) models.

Data migration

Products, users, people and POS settings prepared and imported from spreadsheets, plus the POS product catalogue with images.

Process design (BPMN)

Procurement and campus recruitment processes modelled in BPMN before they were built.

// how i work

AI-native, human-checked

I use AI to move fast, and engineering discipline to make what it builds safe to ship.

01

Prototype fast with AI

Lovable and Google Stitch for first screens, Claude Code and Cursor for the engineering. A working version in days, not months.

02

Then harden it

Strict TypeScript as a build gate, attack suites that run as real signed-in users, DAST scans, and every rule with a value enforced on the server — never in the browser.

03

Write it down

Every project ships a README plus a HANDOVER or DEVELOPMENT file that says which parts look wrong but are deliberate — for the next human or AI.
