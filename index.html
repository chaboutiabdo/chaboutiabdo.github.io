The AI inside THE SMART

Every AI call in THE SMART goes through one server function. The browser never talks to Gemini and the API key never leaves the server — so cost, abuse and quality are controlled in one place.

AI tutor · maths · limits
كيف أحسب نهاية (x² − 1)/(x − 1) عندما يؤول x إلى 1؟
١. التعويض المباشر يعطي 0/0 — حالة عدم تعيين. ٢. نحلّل البسط: x² − 1 = (x − 1)(x + 1) ٣. نختصر على (x − 1) فيبقى x + 1 ٤. النهاية = 1 + 1 = 2 ✓

Answers in Arabic with Latin notation, step by step — the way a BAC paper is written.

One door for every AI call

01
Student

asks a question, opens a mistake or a BAC paper

02
gemini-chat

session + premium check · 60 calls per rolling 24 h · input caps · closed subject list

03
Cache first

each paper is solved once, then shared by every student

04
Gemini

5-model fallback chain: on 429, 503 or timeout, the next model answers

AI tutor

Multi-turn Arabic chat tied to a subject and chapter from a closed list — no free text reaches the prompt through them, so no prompt injection there.

Explain my mistake

Explains a question the student got wrong. Ownership is checked on the server: a wrong id and someone else’s id both return 404. Saved, so reopening costs nothing.

AI flashcards

5–10 cards for one chapter in schema-constrained JSON, de-duplicated against the student’s deck. One malformed card rejects the whole batch.

AI exam solver

The one multimodal call: the paper’s PDF goes to Gemini as a native attachment. Grounded in the official solution when it exists, solved from scratch when not — and the student sees which.

Built to run on Gemini’s free tier

Quota is charged before the call, so a failing generation can’t loop for free.

A prewarm script solves every paper ahead of time — students get cached answers instantly.

SSRF guard on paper URLs: https only, no localhost, private ranges or cloud metadata (169.254.*).
